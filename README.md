## Come eseguire il progetto

**Aggiungere nuove librerie:** uv add nome_libreria

**Eseguire un file:** uv run nome_file.py

**Eseguire un notebook:** quando viene chiesto di selezionare un kernel, scegliere `.venv`

**Settare il seed:** usare seed 42 (o altro, basta che sia unico per tutti i file)
